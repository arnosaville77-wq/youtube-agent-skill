# البرومبت الكامل لموقع SportsArena

> انسخ كل ما تحت هذا السطر والصقه في Claude Code (أو أي وكيل برمجة) لإعادة بناء الموقع كاملاً من الصفر بكل ما فيه.

---

أنت مطوّر ووردبريس خبير. ابنِ موقعاً رياضياً عربياً كاملاً على ووردبريس باسم مبدئي **SportsArena**: نتائج المباريات ومواعيدها وجداول الترتيب والهدافين والتشكيلات والإحصائيات والأخبار، لكرة القدم في كل المسابقات ولرياضات أخرى (كرة السلة، التنس، الفورمولا 1، كرة اليد، الكرة الطائرة، الملاكمة والفنون القتالية). الموقع عربي أولاً (RTL)، وقابل للعمل بعدة لغات، ومهيّأ لمحركات البحث ولسياسات Google AdSense ولمؤشرات Core Web Vitals.

إن احتجت قراراً مني لا يمكن استنتاجه من هذا الطلب، اسألني قبل التنفيذ.

## 1) القيود الصارمة (لا استثناء فيها)

1. **ممنوع تماماً أي بث مباشر**: لا بث، لا روابط بث، لا تضمين بث، لا iframe لقنوات. حقل «القناة الناقلة» نصّي فقط، وأي رابط يُكتب فيه يُحذف تلقائياً عند الحفظ.
2. **لا شعارات أندية ولا صور لاعبين محمية** إلا إذا كان مزوّد البيانات يمنح ترخيصاً: عرض شعارات المزوّد خيار في الإعدادات، معطّل افتراضياً، مع تنبيه واضح بالحقوق. أعلام الدول (مكتبة flag-icons برخصة MIT، مرفقة محلياً) تظهر دائماً.
3. **لا تحديث تلقائي للصفحة كاملة**: النتائج الحية تُحدَّث عبر REST لجزء النتيجة فقط، فلا تُعاد تحميل الإعلانات.
4. **لا إعلانات ملاصقة لأزرار أو روابط**: هوامش واضحة، ومساحة محجوزة لكل خانة، ولا إعلان داخل قائمة مباريات بطولة (بين المجموعات فقط).
5. **مفاتيح الـ API تُدخل من صفحة إعدادات في لوحة التحكم، لا تُكتب في الكود**. لا تُعاد طباعتها في النموذج (آخر 4 أحرف فقط)، ويمكن تعريفها اختيارياً كثوابت في `wp-config.php` (مثل `SPORTSARENA_API_FOOTBALL_KEY`).
6. **لا أسرار في الكود أو في المستودع**.
7. **الأمان**: sanitize لكل مدخل، escape لكل مخرج، nonce وفحص صلاحيات (capabilities) لكل نموذج وإجراء إداري وطلب AJAX/REST يغيّر شيئاً.
8. **لا تختلط لغتان في صفحة واحدة**: الصفحة الإنجليزية إنجليزية بالكامل، والفرنسية فرنسية بالكامل، والعربية عربية بالكامل.

## 2) البنية

- **إضافة `sportsarena-core`**: كل المنطق (أنواع المحتوى، البيانات والمزامنة والكاش، SEO وSchema، الإعلانات والموافقة، الصفحات الإلزامية، اللغات، البيانات التجريبية، لوحة التحكم، WP-CLI). المحتوى لا يضيع عند تغيير القالب.
- **قالب `sportsarena-theme`**: العرض فقط. بلا page builder، بلا jQuery في الواجهة، JS واحد صغير بـ `defer`.
- المتطلبات: WordPress 6.5+، PHP 8.1+، GD.
- كود منظم بـ namespace `SportsArena\Core` و autoloader بسيط (`includes/class-*.php`، مجلدات فرعية `data/` و`seo/` و`ads/` و`admin/`).
- **WordPress Coding Standards** (ملف `phpcs.xml.dist` و`composer.json`) بصفر أخطاء، وسكربت `bin/build.sh` يشغّل `php -l` و PHPCS ثم يُنشئ `dist/sportsarena-core.zip` و`dist/sportsarena-theme.zip`.
- كل نصوص الواجهة ولوحة التحكم قابلة للترجمة (text domains: `sportsarena-core` و`sportsarena-theme`)، مع ملفات `.pot`.

## 3) أنواع المحتوى والروابط

- أنواع المحتوى: `match` (مباراة)، `team` (فريق)، `competition` (بطولة)، `player` (اختياري).
- التصنيفات: `sport` (الرياضة)، `season` (الموسم)، `country` (الدولة). الأخبار مقالات عادية تُربط بالفرق والبطولات والرياضة.
- الروابط:
  - المباراة: `/match/real-madrid-vs-barcelona-2026-10-26/`
  - البطولة: `/competition/premier-league/` وتبويباتها روابط حقيقية قابلة للفهرسة: `/matches/` و`/standings/` و`/scorers/`
  - الفريق: `/team/al-ahly/` — الرياضة: `/sport/basketball/`
  - الأيام: `/matches-today/` و`/matches-tomorrow/` و`/matches-yesterday/` و`/matches/2026-10-26/`
  - المباريات الكبرى: `/big-matches/`
  - الأخبار: `/news/` وأقسامها `/category/football-news/`...
- قواعد rewrite مع flush مرة واحدة عند تغيّر نسخة القواعد.
- المباريات القديمة لا تُحذف، وتبقى مفهرسة كأرشيف.

## 4) طبقة البيانات والمزامنة

- واجهة موحّدة (Adapter) `SportsArena\Core\Data\Provider` ومحوّلات جاهزة:
  - **API-Football** (api-sports.io): مباشر، مواعيد، أحداث، تشكيلات، إحصائيات، مواجهات سابقة، ترتيب، هدافون، شعارات.
  - **API-Basketball** (api-sports.io): المواعيد والنتائج والترتيب.
  - **TheSportsDB**: التنس، الفورمولا 1، كرة اليد، الكرة الطائرة، الملاكمة/MMA (المواعيد والنتائج).
  - إضافة مزوّد جديد عبر الفلتر `sportsarena_providers`.
- معرّفات الدوريات الافتراضية لـ API-Football: 39 الإنجليزي، 140 الإسباني، 135 الإيطالي، 78 الألماني، 61 الفرنسي، 2 دوري الأبطال، 3 الدوري الأوروبي، 1 كأس العالم، 4 أمم أوروبا، 9 كوبا أمريكا، 6 أمم أفريقيا، 307 السعودي، 233 المصري، 200 المغربي، 12 أبطال أفريقيا. قابلة للتعديل.
- جدول المزامنة (WP-Cron):

| المهمة | التكرار | ملاحظات |
|---|---|---|
| المباريات الحية | كل 60 ثانية (قابل للتعديل، لا يقل عن 60) | تستدعي الـ API فقط إذا وُجدت مباراة حية أو ستبدأ خلال 10 دقائق، وتجلب التشكيلات قبل البداية بساعة. |
| مباريات اليوم والغد | كل 30 دقيقة | مع أحداث وتشكيلة وإحصائيات المباريات المنتهية (20 مباراة في طلب واحد). |
| الترتيب والهدافون ونتائج الأمس | كل 6 ساعات | طلبان لكل بطولة متابعة. |
| الصيانة | يومياً | تنظيف السجل والكاش القديم. |

- الكاش: Transients (تدعم Redis/Memcached) + جدول `{prefix}sa_cache` يحتفظ بآخر استجابة سليمة ويقدّمها عند تعطل المزوّد أو نفاد الرصيد. مفتاح كاش الاستعلامات يتضمن رقم نسخة البيانات ولغة الصفحة.
- حدود الطلبات: عدّاد يومي وفي الدقيقة لكل مزوّد، قراءة ترويسات `x-ratelimit-*`، وإيقاف مؤقت عند 429.
- سجل أخطاء في لوحة التحكم (جدول `{prefix}sa_logs`).
- REST: `/wp-json/sportsarena/v1/live` لنتائج المباريات الحية (`max-age=30`)، والبحث السريع عن فريق أو بطولة.
- أوامر WP-CLI: `wp sportsarena sync live|daily|tables`، `pages`، `seed`، `unseed`، `adsense-check`، `relocalize`.
- في README: شرح إعداد Cron حقيقي على الاستضافة (`DISABLE_WP_CRON` + مهمة cron كل دقيقة بـ wget أو WP-CLI).

## 5) لوحة التحكم (قائمة SportsArena)

- **البيانات والمزامنة**: المفاتيح، معرّفات الدوريات، رياضات TheSportsDB، الحد اليومي/الدقيقة، فاصل التحديث الحي، تفعيل المزامنة، حالة المزوّدين والتشغيل التالي لكل مهمة، «عرض شعارات المزوّد»، «حفظ الشعارات على موقعك»، **عرض المواعيد** (GMT أو توقيت جهاز الزائر)، اسم التوقيت الأصلي، Google News Sitemap، مواقع اللغات الأخرى (hreflang)، **الأندية الكبرى**، **لغات الموقع** و**اسم الموقع بكل لغة**، حذف البيانات عند الإلغاء.
- **الإعلانات**: معرّف الناشر، Auto Ads، الخانات اليدوية، ads.txt.
- **الموافقة على الكوكيز**: Consent Mode v2، وضع CMP خارجية أو لافتة مدمجة.
- **السجل**.
- **الأدوات**: إنشاء/حذف البيانات التجريبية، مزامنة يدوية، إنشاء الصفحات الإلزامية، تنزيل الشعارات الآن، «تحويل المحتوى إلى لغة الموقع».
- **فحص AdSense** (انظر القسم 12).
- صناديق تعديل (meta boxes): بيانات المباراة (النتيجة، الحالة، الدقيقة، الملعب، الحكم، القناة نصّاً، الأحداث، التشكيلة، الإحصائيات، «مباراة كبرى»: تلقائي/نعم/لا، زر التحديث من المزوّد)، بيانات الفريق (الاسم الإنجليزي، المختصر، التأسيس، الملعب، رابط الشعار)، الترتيب والهدافون للبطولة، وفي الخبر: الفرق والبطولات المرتبطة و**لغة الخبر**.

## 6) صفحات الواجهة

- **التصميم العام على طريقة مواقع النتائج (مثل Flashscore)، بألوان كحلي داكن + أحمر**، مع شعار واسم الموقع الخاصين (لا تنسخ شعار أو اسم أي موقع آخر).
- **الرئيسية** بثلاثة أعمدة على الحاسوب: يمين (في RTL) «أهم البطولات» بشعاراتها و«الدول» (كل دولة تُفتح لتعرض بطولاتها)؛ الوسط **مركز المباريات**؛ اليسار «المباريات الكبرى» وآخر الأخبار وإعلان جانبي ثابت. على الجوال المباريات أولاً. تحتها أحدث الأخبار ببطاقات.
- **مركز المباريات** (الرئيسية وصفحات الأيام): العنوان، التنقل بين الأيام بأسهم + تقويم، تبويبات «الكل / مباشر (عدد) / النتائج / القادمة / المفضلة»، شرائح تصفية حسب الرياضة، ثم البطولات: رأس «الدولة: البطولة» مع نجمة ورابط «الترتيب»، وكل مباراة سطر: نجمة، الوقت (أو الدقيقة بالأحمر للمباشر)، الفريقان فوق بعض بشعاريهما، النتيجتان فوق بعض (الفائز بخط عريض). إعلان بين كل 3 بطولات ويختفي أثناء التصفية.
- **«مفضلتي» بدون تسجيل**: نجمة بجانب كل مباراة وبطولة، تُحفظ في localStorage فقط، وتظهر في نافذة البروفيل مع عدّاد وفي تبويب «المفضلة».
- **المباراة**: لوحة نتيجة بالشعارين، الحالة والدقيقة، معلومات (الملعب والمدينة، الحكم، القناة الناقلة نصّاً)، الأحداث (أهداف مع صانعها، بطاقات، تبديلات)، التشكيلتان والبدلاء والمدرب، الإحصائيات بأشرطة، المواجهات السابقة، قسم «معاينة/تحليل» يكتبه المحرر، الأخبار المرتبطة. تحديث حي لجزء النتيجة فقط.
- **البطولة**: رأس بالشعار، تبويبات المباريات/الترتيب/الهدافون.
- **الفريق**: الشعار، المباريات القادمة والأخيرة، الأخبار المرتبطة.
- **الرياضة**: مباريات وأخبار الرياضة.
- **المباريات الكبرى** `/big-matches/`: المباريات القادمة والمباشرة بين الأندية الكبرى، ثم قسم **دوري أبطال أوروبا** (القادمة وآخر النتائج ورابط الترتيب)، ثم آخر نتائج المباريات الكبرى. المباراة الكبرى = ناديان من قائمة الأندية الكبرى (افتراضياً أكبر أندية أوروبا والعرب: ريال مدريد، برشلونة، الهلال، النصر، الأهلي، الزمالك، الوداد، الرجاء...)، أو مختارة يدوياً من صفحة المباراة.
- **الهيدر** كحلي داكن: الشعار في البداية، وفي الطرف الآخر أزرار دائرية: **البحث** (نافذة بحث مع اقتراحات)، **اللغة 🌐**، **البروفيل** (مفضلتي + الوضع الداكن). تحته **القائمة الكبيرة**: الرياضات بأيقوناتها ثم المباريات الكبرى ودوري الأبطال والبطولات والأخبار (تمرير أفقي على الجوال).
- **الفوتر**: اسم الموقع ووصفه، تنبيه «لا نقدّم أي بث مباشر»، روابط الصفحات الإلزامية، «إعدادات الخصوصية»، **قسم «اللغة»**، وحقوق النشر.
- 404، البحث، الأرشيف، التعليقات (نموذج مترجم).
- وضع داكن، تصميم Mobile First، RTL للعربية و LTR لغيرها، خط Cairo مع خط بديل محلي بنفس المقاييس.

## 7) الأخبار

- صفحة **«الأخبار»** `/news/` بقالب «الأخبار (حسب الرياضة)»: أحدث 5 أخبار، ثم قسم لكل رياضة فيه 4 أخبار ورابط «المزيد»، مع خانة إعلان بين كل قسمين.
- أقسام جاهزة (تصنيفات بوصف): أخبار كرة القدم، الانتقالات، أخبار كرة السلة، أخبار التنس، أخبار الفورمولا 1، أخبار كرة اليد، أخبار الكرة الطائرة، أخبار الملاكمة والفنون القتالية، تحليلات ومقالات رأي.
- ربط تلقائي بين القسم والرياضة في الاتجاهين، واكتشاف الفرق والبطولات المذكورة في الخبر وربطها، وتحويل أول ذكر لها إلى رابط (3 روابط كحد أقصى).
- الأخبار ذات الصلة والمباريات القادمة للفريق في صفحة الخبر.

## 8) الشعارات والأعلام

- شعارات المزوّد تظهر في كل أماكنها عند تفعيل الخيار: صفوف المباريات، لوحة النتيجة، الشريط الحي، الترتيب، رؤوس البطولات، صفحات الفرق، الشريط الجانبي، بطاقات المباريات الكبرى.
- «حفظ الشعارات على موقعك»: تنزيل بدفعات كل ساعة إلى `uploads/sportsarena-logos/` بحجم 128px WebP، وزر «تنزيل الشعارات الآن».
- الصورة البارزة للفريق/البطولة (شعار تملك حقه) تُعرض قبل شعار المزوّد، ويمكن لصق «رابط الشعار» يدوياً.
- بدائل بلا صور مكسورة ولا إزاحة: شعار بطولة غير متاح → علم دولتها أو كرة أرضية للبطولات الدولية؛ شعار نادٍ غير متاح → درع محايد بنفس الحجم.
- المنتخبات ولاعبو الرياضات الفردية يأخذون علم الدولة.

## 9) التوقيت

- افتراضياً **بتوقيت جرينتش (GMT)** لكل الزوار مع كلمة GMT بجانب الوقت (مثل «19:00 GMT»)، وتُحسب صفحات اليوم/الغد/الأمس بيوم جرينتش.
- خيار بديل: توقيت جهاز كل زائر (يحوّله المتصفح).

## 10) اللغات

- **ترجمات جاهزة** (`.po` و`.mo`) للإضافة والقالب بسبع لغات: `en_US`، `fr_FR`، `es_ES`، `de_DE`، `it_IT`، `pt_BR`، `tr_TR`.
- مع تغيير لغة الموقع من الإعدادات > عام يتغيّر كل شيء: الواجهة، لوحة التحكم، حالات المباريات، الإحصائيات، العناوين الذكية وSchema وصور المشاركة، أسماء الفرق والبطولات والرياضات والدول (بالعربية من قاموس على الموقع العربي، وبالإنجليزية كما يرسلها المزوّد في غيره، دون تعديل البيانات المحفوظة)، أسماء الشهور والأيام (مع بديل مدمج للغات السبع إلى أن تُنزَّل حزمة اللغة).
- **إعادة توطين المحتوى المولَّد**: الصفحات الإلزامية وأقسام الأخبار والبيانات التجريبية تُكتب بلغة الموقع، وعند تغيير اللغة تُعاد كتابتها تلقائياً باللغة الجديدة (ما عدّله المستخدم بنفسه يبقى كما هو، عبر بصمة hash)، ومن زر في الأدوات أو `wp sportsarena relocalize`.
- ويدجت ووردبريس الافتراضية تُنقل خارج الشريط الجانبي عند تفعيل القالب لأن عناوينها محفوظة بلغة التثبيت.
- **وضع متعدد اللغات مدمج (بدون إضافات)**:
  - لغة الموقع على الرابط الرئيسي `/`، وكل لغة إضافية تحت رمزها: `/en/`، `/fr/`، `/es/`، `/de/`، `/it/`، `/pt/`، `/tr/` (أو `/ar/` إن كانت لغة الموقع غير العربية). تُختار من «لغات الموقع» (الإنجليزية والفرنسية مفعّلتان افتراضياً).
  - كل طلب تحت بادئة يعمل بالكامل بتلك اللغة: الواجهة، التواريخ، الأسماء (فرق، بطولات، لاعبون، مدربون، حكام، ملاعب، مدن)، الصفحات الإلزامية وأقسام الأخبار غير المعدّلة، `<html lang>` والاتجاه، واسم الموقع ووصفه من حقل «اسم الموقع بكل لغة» (`en=Name|Tagline`).
  - المباريات والفرق والبطولات بيانات مشتركة تظهر في كل اللغات. الأخبار لكل لغة أخبارها (meta لغة الخبر + مجموعة ترجمة تربط الترجمات ببعضها)، وتُفلتر الاستعلامات حسب اللغة (مع عدم ابتلاع شرط اللغة داخل meta_query بعلاقة OR). خبر يُفتح برابط لغة أخرى يُحوَّل 301 إلى رابطه الصحيح. الأخبار الموجودة قبل التفعيل تُعلَّم بلغة الموقع مرة واحدة.
  - روابط الموقع كلها تأخذ بادئة اللغة الحالية، بدون حلقات إعادة توجيه.
  - وسوم `hreflang` لكل لغة + `x-default`.
  - **مبدّل لغة للزوار**: زر 🌐 في الهيدر يعرض رمز اللغة الحالية (`AR`/`EN`/`FR`) ويفتح قائمة بأسماء اللغات بلغاتها الأصلية (العربية، English، Français...) مع تمييز اللغة الحالية، ويُغلق بالنقر خارجه أو Esc؛ و**قسم «اللغة» في الفوتر** بأزرار لكل اللغات. في صفحة خبر، المبدّل ينقل إلى ترجمته مباشرة، وإلا إلى الصفحة نفسها في اللغة الأخرى.
  - إن فُعّلت Polylang أو WPML يتوقف الوضع المدمج تلقائياً، ويعرض نفس الزر وقائمة الفوتر لغات تلك الإضافة (مع ملف `wpml-config.xml`).
  - بديل موثّق في README: موقع مستقل لكل لغة مع حقل «مواقع اللغات الأخرى (hreflang)».

## 11) SEO

- متوافق مع Rank Math وYoast: عند تفعيل أحدهما لا تُطبع أي meta مكررة، وتُمرَّر العناوين والأوصاف الذكية عبر فلاترهما فقط إذا لم يكتب المحرر عنواناً مخصصاً. بدونهما يوجد بديل داخلي كامل.
- عناوين ذكية، مثال: «ريال مدريد ضد برشلونة اليوم: موعد المباراة والتشكيلة والنتيجة المباشرة – الدوري الإسباني»، وبعد النهاية: «ريال مدريد 2-1 برشلونة: نتيجة المباراة والأهداف والتشكيلة – الدوري الإسباني». وأوصاف meta تلقائية.
- Schema JSON-LD: `SportsEvent` لكل مباراة، `SportsTeam`، `SportsOrganization`، `NewsArticle`، `BreadcrumbList`، `WebSite` مع `SearchAction`، `Organization`.
- Breadcrumbs ظاهرة في كل الصفحات.
- Sitemaps: المباريات والفرق والبطولات والرياضات وصفحات الأيام والمباريات الكبرى، و**Google News Sitemap** `/news-sitemap.xml` (أخبار آخر 48 ساعة) في robots.txt.
- canonical صحيح لكل صفحة، و noindex للبحث الداخلي والتواريخ الفارغة والتبويبات الفارغة.
- Open Graph وTwitter Cards مع **صورة مشاركة مولَّدة لكل مباراة** بمكتبة GD (اسما الفريقين + البطولة + التاريخ) مع تشكيل صحيح للحروف العربية، في `uploads/sportsarena-og/`.
- ربط داخلي: المباراة ← البطولة ← الفريقان ← الأخبار.

## 12) AdSense والموافقة

- معرّف الناشر `ca-pub-...`، سكربت AdSense مرة واحدة في `<head>` بعد Consent Mode.
- **ads.txt** يُنشأ تلقائياً في الجذر (أو ديناميكياً إن تعذّرت الكتابة)، ولا يُستبدل ملف موجود لم تنشئه الإضافة.
- Auto Ads أو خانات يدوية بمساحة محجوزة (جوال/ديسكتوب) وعنوان صغير «إعلان»:

| الخانة | الموضع | الارتفاع المحجوز |
|---|---|---|
| `header` | أسفل الهيدر | 100 / 90 px |
| `in_article` | داخل الخبر بعد الفقرة الثانية | 280 / 280 px |
| `in_article_2` | داخل الخبر الطويل بعد الفقرة السادسة (8 فقرات فأكثر) | 280 / 280 px |
| `article_bottom` | أسفل الخبر قبل الأخبار ذات الصلة | 280 / 250 px |
| `in_feed` | بين بطاقات الأخبار (كل 6) وبين أقسام صفحة الأخبار | 280 / 250 px |
| `sidebar` | الشريط الجانبي (sticky على الديسكتوب) | 280 / 600 px |
| `between_lists` | بين مجموعات البطولات (كل 3 بطولات) | 280 / 250 px |
| `match_bottom` | أسفل صفحة المباراة | 280 / 250 px |

- لا إعلانات ولا سكربت في: 404، نتائج البحث الفارغة، صفحات الخصوصية والتواصل والشروط وإخلاء المسؤولية. عدد الإعلانات متوازن مع طول المحتوى. للمدير فقط: إطار منقّط مكان كل خانة مفعّلة قبل إدخال المعرّف (فلتر `sportsarena_ad_placeholders`).
- **Consent Mode v2**: القيم مرفوضة افتراضياً لزوار أوروبا وبريطانيا وسويسرا ومسموحة لغيرهم، قبل أي وسم من Google. وضع «CMP خارجية» (رسالة GDPR من AdSense) أو لافتة مدمجة احتياطية (قبول/رفض + رابط الخصوصية + «إعدادات الخصوصية» في الفوتر).
- **فحص جاهزية AdSense** في لوحة التحكم (و`wp sportsarena adsense-check`): 25 نقطة، لكل منها طريقة الإصلاح:
  - الموقع: HTTPS، الظهور لمحركات البحث، الروابط الدائمة، الاسم والوصف.
  - الصفحات والمحتوى: الصفحات الإلزامية، نموذج التواصل، روابط الفوتر، 25+ مقالاً أصلياً، متوسط 300+ كلمة، معاينات المباريات، حذف البيانات التجريبية والمحتوى الافتراضي.
  - سياسات المحتوى: لا روابط أو عبارات بث، لا مراهنات، حقوق الشعارات.
  - الإعلانات: معرّف الناشر، ads.txt (يُفتح فعلياً)، أماكن الإعلانات.
  - الخصوصية: سياسة الخصوصية تذكر AdSense والكوكيز، CMP، Consent Mode v2.
  - التقنية: خريطة الموقع، الكاش، Cron حقيقي.

## 13) الصفحات الإلزامية

- تُنشأ عند التفعيل وتُربط في الفوتر، ولا تُستبدل صفحة موجودة: **من نحن، اتصل بنا (مع نموذج تواصل مدمج `[sportsarena_contact_form]`: nonce + honeypot + حد للرسائل)، سياسة الخصوصية (تذكر AdSense والكوكيز والأطراف الثالثة)، الشروط والأحكام، إخلاء المسؤولية**، وصفحة الأخبار.
- نصوصها تأخذ اسم الموقع ونطاقه وبريده تلقائياً، وتُترجم بلغة كل صفحة.

## 14) الأداء (Core Web Vitals)

- CSS حرج inline، والباقي غير حاجب، JS واحد بـ `defer` بلا jQuery.
- Cairo من Google Fonts مع `font-display: swap` و`preconnect` وخط بديل بنفس المقاييس الرأسية (لا اهتزاز).
- WebP تلقائياً للصور المرفوعة، `loading="lazy"` مع أبعاد محددة، الصورة الأولى `fetchpriority="high"`.
- مساحة محجوزة لكل إعلان وشعار، CLS ≈ 0. الهدف: Lighthouse جوال 95+.
